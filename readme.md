# 🪙 TAT Wallet

کیف پول دیجیتال چندارزی با سکه اختصاصی TAT

## ✨ ویژگی‌ها

- 🪙 **سکه TAT اختصاصی** (دو رو، سه‌بعدی، VIP)
- 💳 **کارت بانکی سه‌بعدی چرخان**
- 💱 **بازار چندارزی** (تتر، طلا ۱۸/۲۴، اونس)
- 💼 **پرتفوی و دارایی‌ها**
- 💰 **سپرده‌گذاری** (۴ نوع، سود ۲۰-۳۶٪)
- 🎮 **اپ‌های متصل**
- 📊 **نمودار ارزش**
- 🔔 **مرکز اعلان**
- 🌙 **تم تیره**

## 🚀 اجرا

1. سه فایل رو دانلود کن
2. توی یه پوشه بذار
3. `index.html` رو باز کن

## 🎨 تکنولوژی

- HTML5
- CSS3 (Flexbox, Grid, 3D Transforms)
- Vanilla JavaScript
- SVG (سکه اختصاصی)
- PWA Ready

## 📱 پیش‌نمایش

- Splash با سکه TAT
- صفحه ورود
- ۵ تب اصلی: خانه، بازار، دارایی، اپ‌ها، تنظیمات
- مودال‌های: ارسال، دریافت، جزئیات ارز، جزئیات تراکنش، جزئیات اپ، سپرده

## 🪙 سکه TAT

دو رو:
- **رو**: TAT + 2025 (انگلیسی)
- **پشت**: تات + ۱۴۰۵ (فارسی)
