# 🪙 TAT Wallet

کیف پول دیجیتال چندارزی با سکه اختصاصی TAT — ترکیبی از تعامل

---

## ✨ ویژگی‌ها

### 🪙 سکه TAT
- سکه اختصاصی **دو رو** (انگلیسی + فارسی)
- افکت سه‌بعدی + درخشش متحرک
- نسخه VIP (طلایی با تاج)
- چرخش با کلیک

### 💳 کارت بانکی
- کارت **سه‌بعدی چرخان** با ۵ رنگ قابل تغییر
- شماره کارت از `۹۹۰۰ ۶۶۰۰` شروع میشه
- CVV2 + تاریخ انقضا
- **PDF کارت** قابل دانلود

### 🏦 حساب‌های بانکی
- تا **۳ حساب** برای هر کاربر
- حساب اصلی، ذخیره، VIP
- شماره حساب ۱۲ رقمی
- **شبا** با فرمت `TAT` + ۲۴ رقم
- انتخاب حساب پیش‌فرض

### 💸 انتقال TAT
- ارسال به آیدی یا شماره کارت
- **تأیید با رمز دوم** (۶ رقمی، هش‌شده)
- محافظت از حمله بروت‌فورس
- قفل موقت بعد از ۳ تلاش ناموفق

### 💱 بازار چندارزی
- TAT، تتر، طلا ۱۸، طلا ۲۴، اونس
- نمودار ارزش
- مشاهده جزئیات

### 💼 پرتفوی
- مجموع دارایی
- نمودار دایره‌ای توزیع
- لیست دارایی‌ها

### 💰 سپرده‌گذاری
- ۴ نوع: انعطاف‌پذیر، ۱ ماهه، ۳ ماهه، ۶ ماهه
- سود ۲۰٪ تا ۳۶٪ سالانه
- واریز سود روزانه

### 🎮 اکوسیستم اپ‌ها
- لیست اپ‌های متصل
- مشاهده مجوزها
- جزئیات هر اپ

### 🔔 مرکز اعلان
- اعلان تراکنش
- اعلان جایزه
- اعلان قیمت

### 🎨 رابط کاربری
- تم تیره لوکس
- حالت روشن (Light Mode)
- فارسی RTL
- فونت وزیرمتن
- ریسپانسیو کامل
